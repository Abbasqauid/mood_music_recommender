MoodTune – AI-Based Mood Music Recommender 🎧

MoodTune is a Python-based mood music recommendation application that helps users discover music based on their current emotions, preferred genres, and language. It features an interactive chatbot, personalized music recommendations, and a playlist builder to create and manage music collections according to individual moods.

Project Overview:
MoodTune is developed using Python 3.10 and Streamlit. It uses Apple's iTunes Search API to retrieve real music tracks, artist information, album artwork, and available song previews.

Key Features:
- 15 Mood Options: Happy, Sad, Relaxed, Energetic, Romantic, Angry, Anxious, Nostalgic, Focused, Motivated, Lonely, Hopeful, Stressed, Adventurous, and Sleepy.
- Music Recommendations: Discover songs based on mood, genre, language, and listening preferences.
- Interactive Chatbot: A guided chatbot that asks users about their current mood, preferred music genre, and language.
- Multiple Music Genres: Explore Pop, Rock, Hip-Hop, Jazz, EDM, Classical, R&B, Lo-fi, and more.
- Multi-Language Support: Search for music in English, Urdu, Hindi, Punjabi, Arabic, Korean, Spanish, and other languages.
- Personalized Playlists: Add, remove, and manage favourite songs.
- Playlist Export: Download personalized playlists in CSV format.
- Music Previews: Listen to available song previews and access original music links.
